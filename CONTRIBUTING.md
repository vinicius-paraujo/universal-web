# Contribuição

## Preparação

1. Use uma versão compatível do Node.js.
2. Execute `npm install`.
3. Crie uma branch curta e relacionada a uma única alteração.

## Verificação

Antes de solicitar revisão, execute:

```sh
npm run check
npm run build
```

Inclua somente arquivos públicos necessários ao site. Não adicione documentos administrativos, dados pessoais, materiais sem autorização ou segredos de ambiente.

## Alterações de conteúdo

- Confirme nomes, resultados, publicações e parcerias antes de publicá-los.
- Informe a origem, o crédito e a licença de imagens e materiais de terceiros.
- Mantenha as versões em português e inglês correspondentes.
- Não altere marcas institucionais ou de projetos parceiros.
